## SyncBridge 0.1.16

ダウンロードするのは **SyncBridge-Setup-0.1.16.exe**（インストーラー）です。
zip（**SyncBridge-0.1.16.zip**）も同じ中身です。「Source code」は開発用のファイルで、インストールには使えません。

### 0.1.9 からの主な変更

#### インストールと更新
- **インストーラー（EXE）になりました。** ダブルクリックして「インストール」を押すだけです（管理者権限は不要）。
  アンインストールは Windows の「設定」→「アプリ」から行います。zip（Install.bat）も引き続き使えます
- **パネルから更新できるようになりました。** Maya と After Effects の SyncBridge パネルの上のメニュー
  「ヘルプ」→「SyncBridge について / 更新…」で、GitHub にある版の一覧が出ます。版を選んで「インストール」を押すと、
  インストーラー（古い版は zip）をダウンロードして開きます。次の版からは、ここから更新できます
  - この更新の仕組みは仮のもので、今後変わることがあります

#### パネル
- Maya と AE のパネルを、状態の表示とタブ（タイムワープ / 同期・設定 / レイヤー / その他）で整理しました
- AE のレイヤーを選んで追加すると、それぞれの Maya レイヤーを自動で作ります（Film Translate・Scale・Roll でつなぎます。
  カメラと表示するオブジェクトはレイヤーマップで設定します）
- リアルタイム同期（AE → Maya）: つないだ AE のレイヤーの位置やキーを変え終えると、Maya の専用カメラに自動で反映します

#### SyncBridge ビューアー
- **2D パン・ズーム:** Maya の 2D Pan/Zoom ツール（\ キー＋ドラッグ）で、すべてのレイヤーと枠が一緒にズーム・パンします。
  「ズームを戻す」で余白の大きさに戻ります。余白「なし」のときは 2D Pan/Zoom を切ります
- **編集中のレイヤー:** ビューでほかのレイヤーのオブジェクトをクリックすると、そのレイヤーが編集中になり、選択・移動が
  そのレイヤーの見え方どおりになります
  - NURBS カーブのコントローラーやロケーターのクリックでも切り替わります
  - アウトライナーなどで 1 つのレイヤーのものだけを選んでも切り替わります。Undo で選択が戻ると、カメラも戻ります
  - 別のレイヤーのものや、どのレイヤーにもないものが選択に入ったときは、カメラを保ち、マニピュレーターが見た目と
    合わないことを下に知らせます
  - ビューに描かれていないもの（ほかのレイヤーや、どのレイヤーにもないオブジェクト）が、クリックや囲みで選ばれないようにしました
  - Shift のクリックはトグル、Ctrl+Shift は追加（Maya と同じ）。非表示のレイヤーは編集中にしません
- マニピュレーターのドラッグで選択が外れる問題、レイヤーを切り替えると選択が消える問題を直しました
- **解像度の枠:** Maya のレンダー設定の解像度で描きます（AE と接続していなくても合います）。ボタンで出す・消すができます
- **任意の枠:** 入力した大きさの枠（水色）も出せます（AE のメインのコンポが絵より広いときなど）
- **枠の外の濃さ**を変えられます
- ビューアーでは Maya の解像度ゲート・フィルムゲートを使えません（レイヤーが枠からずれるため）。ON にすると警告して OFF に戻します

### 注意（0.1.9 から更新する場合）
- 0.1.9 にはパネルからの更新がないので、今回は **SyncBridge-Setup-0.1.16.exe** を自分で実行してください
- インストーラーで入れたあとは、アンインストールは「設定」→「アプリ」からになります（`Uninstall.bat` はなくなります）
- After Effects のパネルで Node.js を使うようになりました（更新の一覧の取得のため）。パネルの更新の画面が使えない場合は、
  お知らせください

### インストール
1. **SyncBridge-Setup-0.1.16.exe** をダブルクリック
   （「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」。署名のないインストーラーのため）
2. 「インストール」を押す。Maya と After Effects は終了しておいてください
3. Maya を起動し、シェルフの「SyncBridge」タブのボタンを押す
4. After Effects を起動し「ウィンドウ」→「エクステンション」→「SyncBridge」

zip の場合は、**SyncBridge-0.1.16.zip** を「すべて展開」して `Install.bat` をダブルクリックしてください。

- Maya 2023 / 2024 / 2025 以降（動作確認は Maya 2023、2024、2025）
