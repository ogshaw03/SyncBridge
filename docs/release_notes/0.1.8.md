## SyncBridge 0.1.8

ダウンロードするのは **SyncBridge-0.1.8.zip** です（「Source code」は開発用のファイルで、インストールには使えません）。

### 0.1.7 からの変更

#### AE のレイヤーの動きを Maya のカメラへ（Pixel Mapping）
- **レイヤーマップ**（Maya のパネルの「レイヤーマップを開く…」）
  - AE のレイヤーと Maya レイヤー（カメラ＋表示するオブジェクト）をノードの線でつなぎます。設定は Maya のシーンに保存されます
  - Maya レイヤーごとに、元のカメラの子として **専用カメラ**（`SB_<レイヤー名>_CAM`）を作ります。元のカメラの値は変えません。
    BG とキャラで同じカメラを使っていても、別々に動かせます
  - つなぎ方は 2 つ
    - **素材カメラ**: AE の素材を書き出したカメラを Maya レイヤーのカメラにすると、基準なしで直接合わせます
      （大判の BG を、引いたりレンズを変えたりしたカメラで書き出した場合など）
    - **相対**: 基準のフレームで Maya と AE の見え方を合わせて記録し、そこからの動きを足します
  - 動かし方（方式）は 2D Pan/Zoom、Film Translate・Scale・Roll（回転も）、Film Translate、Film Offset から選べます
  - 中ボタンのドラッグで画面を動かし、ホイールで拡大縮小します（ノードエディターと同じ）
- **アニメーションの転送**
  - AE のレイヤーの動き（位置・スケール・回転）を、範囲の各フレームのキーとして専用カメラに打ちます
  - 「すべてのアニメーションを転送…」で、つないだすべてのレイヤーを 1 回で。元に戻すときは取り消し（Ctrl+Z）を 1 回
  - AE のヌルを親にした動きと、プリコンポごと動かした動き（PAN）も含めて転送します
  - Maya のレンダー解像度と AE のコンプサイズが違っても（余白を付けて書き出す場合など）合わせます
- **SyncBridge ビューアー**（Maya のパネルの「ビューアーを開く…」）
  - Maya レイヤーをそれぞれの専用カメラで描いて、AE のように重ねて見るウィンドウです。シーンは変えません
  - 下のレイヤー一覧で、ドラッグで重なり順を変え、チェックで表示・非表示を切り替えます
  - 解像度の枠を出し、外側を暗くします。「余白」でビューアーだけを少し縮めて、枠のまわりを見られます
  - ビューアーからもアニメーションを転送できます（上のボタンですべて、一覧の右クリックでそのレイヤーだけ）

#### 時間
- **Origin frame をツールで 1 つに**しました。Maya のシーンに保存され、AE のパネルと共有します。
  アニメーションの転送の範囲は、Maya の再生範囲が初期値になります

#### シーン設定の転送（Maya と AE のパネルの「シーン設定と時間の同期」欄）
- FPS・再生範囲・アニメーション範囲・ピクセル縦横比を、Maya のシーンと AE のアクティブなコンプで合わせます。
  どちらのパネルからでも、どちらの向きにも送れます（送る項目はチェックで選びます）
- 受け取る側に、変わる内容（例「FPS: 24 → 30」）の確認が出ます。元に戻すときは取り消し（Ctrl+Z）を 1 回
- 時間の対応は転送と同じです（Maya の Origin frame = AE のコンプの 0 秒）。AE のコンプの開始フレームも
  Origin frame にするので、AE と Maya で同じフレーム番号が表示されます
- Maya の FPS を変えても、キーはフレーム番号のまま動きません

#### タイムスライダーの同期
- 「タイムスライダーを同期」にチェックを入れると、Maya と AE のどちらで時間を動かしても、もう片方が追従します
- スイッチは Maya と AE のパネルで共通です。「再生中も追従」で、Maya の再生中に AE を動かすかを選べます
- 少し遅れて追従します。Maya から動かしたときの遅れは主に AE の描き直しの時間で、AE のビューアの解像度を
  「1/2」や「1/4」にすると速くなります

#### そのほか
- Maya の確認ダイアログで、長い日本語の行の終わりが切れていたのを直しました
- タイムワープの転送、キーのマーカー、モニターは 0.1.7 と同じです

### 確認の状況
- 利用者の PC の Maya と AE で確認したもの:
  - レイヤーマップ、専用カメラ、アニメーションの転送（1 本ずつ・すべて）、ビューアー（重ねて表示・並べ替え・枠）
  - 素材カメラモード、ビューアーからの転送
  - タイムスライダーの同期（少し遅れあり）
- Maya 2023 / 2024（mayapy）と自動テストで確認し、画面での確認がこれからのもの:
  - ヌルの親・プリコンポの PAN、ビューアーの余白、ビューアーでの半透明の重なり、シーン設定の転送

### アップデートの方法
Maya と After Effects を終了してから、zip を解凍して `Install.bat` をダブルクリックしてください（0.1.7 に上書きされます）。

### インストール（初めての場合）
1. **SyncBridge-0.1.8.zip** をダウンロードして「すべて展開」
2. `Install.bat` をダブルクリック（管理者権限は不要）
3. Maya を起動し、シェルフの「SyncBridge」タブのボタンを押す
4. After Effects を再起動し「ウィンドウ」→「エクステンション」→「SyncBridge」

### 動作環境
- Windows 10 / 11
- Maya 2023 / 2024 / 2025 以降（動作確認は Maya 2023、2024、2025）
- After Effects 2024 以降（動作確認は After Effects 2026 / 26.5）
