SyncBridge {version}  -  Maya と After Effects のタイムワープ転送ツール
======================================================================

Maya の「Scene Time Warp」と After Effects の「タイムリマップ」を、ボタン 1 つで相互に送ります。

■ 動作環境
  - Windows 10 / 11
  - Maya 2023 / 2024 / 2025 以降（確認済みは Maya 2023、2024、2025）
  - After Effects 2024 以降（確認済みは After Effects 2026 / 26.5）
  - 管理者権限は不要です（ご自身のユーザーフォルダだけにインストールします）


■ インストール（最初の 1 回）

  1. この zip を、デスクトップなど好きな場所に解凍します。
     （zip の中から直接開かず、必ず「すべて展開」してください）

  2. 解凍したフォルダの「Install.bat」をダブルクリックします。
     ※「Windows によって PC が保護されました」と出た場合は、
       「詳細情報」→「実行」を押してください。

  3. 「インストールしました」と表示されます。

  4. Maya: Maya を起動すると（起動中なら再起動すると）、シェルフに「SyncBridge」タブが出ます。
     タブの SyncBridge ボタン（青と緑の無限大のマーク）を押すと、パネルが開きます。
     ※ Maya 2023 以降で、この PC で一度でも起動したことのあるバージョンすべてに追加されます。
     ※ 一度も起動していないバージョンの Maya には追加されません。その Maya を一度起動して終了してから、
       もう一度 Install.bat を実行してください。
     ※ それでもタブが出ない場合は、「%LOCALAPPDATA%\Programs\SyncBridge\maya」フォルダの
       「drag_to_maya_SyncBridge.py」を Maya のビューポート（3D の画面）にドラッグ＆ドロップしてください。
       今開いているシェルフに SyncBridge ボタンが追加されます。

  5. After Effects: 起動中なら再起動し、
     「ウィンドウ」→「エクステンション」→「SyncBridge」でパネルを開きます。
     （「エクステンション (従来)」という名前の場合もあります）


■ 使い方

  1. Maya のシェルフの SyncBridge ボタンを押してパネルを開き、「Connect」を押します。
     （初回は数秒かかります。裏で SyncBridge のサーバーが起動します）

  2. After Effects の SyncBridge パネルで「Connect」を押します。
     両方のパネルに、相手が「connected」と表示されれば準備完了です。

  3. After Effects で、送り先 / 送り元のレイヤーを 1 つ選択します。
     （アクティブなコンポの中の、フッテージかプリコンポジションのレイヤー）

  4. どちらかのパネルで送ります。
       「Maya → AE」: Maya の Scene Time Warp を、選択中のレイヤーのタイムリマップへ
       「AE → Maya」: 選択中のレイヤーのタイムリマップを、Maya の Scene Time Warp へ
     受け取る側に確認ダイアログが出るので、OK（Apply）を押すと適用されます。

  5. 元に戻したいときは、受け取った側で「取り消し」（Ctrl+Z）を 1 回押します。
     適用の前には、元の状態のバックアップも自動で保存しています。

  ・Origin frame（原点フレーム）: Maya のどのフレームを AE のコンプ時間 0 / 素材の 0 フレーム目に
    合わせるかです。通常は Maya のレンダーの開始フレームを入れてください。
  ・Mode は通常「editable」のままで構いません。うまく合わない形のときは「precision」を試してください。
  ・AE → Maya では、Maya のシーンにあらかじめ Scene Time Warp を作っておいてください。


■ タイムワープの保存・復元・範囲変更（Maya のパネルの「Scene Time Warp」欄）

  ・保存: 今の Scene Time Warp を名前を付けて保存します。
    （保存先: ドキュメント\maya\SyncBridge\snapshots）
  ・復元…: 保存したタイムワープか、転送前に自動で取ったバックアップを選んで書き戻します。
    「範囲を変更して復元する」にチェックすると、形を保ったまま指定したフレーム範囲に伸縮して戻します。
    Scene Time Warp を作り直したあとでも、前のタイムワープを戻せます。
  ・範囲変更…: 今のタイムワープを、形を保ったまま指定したフレーム範囲に伸縮します
    （ショットの尺を変えたときなど）。値（元のアニメーションの何フレーム目を見せるか）は変わりません。
  ・どれも確認ダイアログが出て、適用前にバックアップを取り、取り消し（Ctrl+Z）1 回で元に戻せます。


■ AE の解像度の枠を Maya のビューに表示

  Maya で余白付きでレンダーし、AE で最終サイズに切り出すときに、最終の範囲を Maya のビューで確認できます。

  1. Maya で、枠を見たいカメラのビューを 1 回クリックしておきます。
  2. 次のどちらかで表示します。
     ・After Effects から: 最終サイズのコンポを開き（タイムラインをクリック）、
       SyncBridge パネルの「解像度の枠を Maya へ」を押す
     ・Maya で大きさを入力: Maya の SyncBridge パネルの「解像度の枠」欄で幅と高さを入れ
       （「プリセット…」からも選べます）、「枠を表示」を押す。AE の接続は不要です
  3. Maya のそのカメラのビューに、オレンジ色の枠が表示されます。
     （Maya のレンダー解像度の中央に、その幅と高さで表示します。ほかのカメラのビューには出ません）

  ・ビューの「表示」メニューの「SyncBridge 解像度の枠」で、ビューごとに出し入れできます。
    「ロケーター」や「プラグインのシェイプ」を隠しても枠は消えません（0.1.7 から）。
  ・枠はレンダーには写りません。シーンにも保存されません（開き直したら、もう一度送ってください）。
  ・消すときは、Maya のパネルの「枠を消す」を押します（取り消し Ctrl+Z では消えません）。
  ・初めて表示するとき、Maya に「Untrusted Plugin Loading - Security Warning」が出ます。
    SyncBridge の枠を描くプラグインです。「Apply to all plugins in this location」にチェックを入れて
    「Allow」を押すと、次からは出ません。「Deny」を押すと枠は表示されません。


■ AE のタイムリマップのキーを Maya のマーカーにする

  AE でキーを打ったタイミングを、Maya のタイムスライダーとビューで確認できます。

  1. After Effects で、タイムリマップのキーがあるレイヤーを 1 つ選択し、
     SyncBridge パネルの「キーのマーカーを Maya へ」を押します（Origin frame の設定を使います）。
  2. Maya に次のように表示されます。
     ・タイムスライダー: キーのフレームにオレンジ色のブックマーク（名前は「AE キー 3/8  素材 36f」など）
     ・ビュー: キーのフレームのときだけ、左上に「● AE キー 3/8  素材 36f」
       （「素材 36f」は、そのキーで表示される素材のフレームです）

  ・マーカーは Maya のシーンに保存されます。AE を開いていなくても、シーンを開き直しても表示されます。
    （ビューの表示は、SyncBridge のパネルを開くと出ます。ブックマークはいつでも出ます）
  ・送り直すと、前に送ったマーカーと置き換わります。自分で作ったブックマークはそのまま残ります。
  ・消すときは、Maya のパネルの「マーカーを消す」を押します（Ctrl+Z で戻せます）。
  ・ビューの表示だけを隠すときは、ビューの「表示」メニューの「SyncBridge キーのマーカー」を切ります
    （「ロケーター」や「プラグインのシェイプ」を隠してもマーカーは消えません。0.1.7 から）。


■ シーン設定の転送（FPS・再生範囲・アニメーション範囲・ピクセル縦横比）

  Maya のシーンと、After Effects のアクティブなコンプの設定を合わせます。どちらのパネルからでも、どちらの向きにも送れます。

  1. パネルの「シーン設定と時間の同期」欄で、送る項目にチェックを入れます。
  2. 「設定 Maya → AE」か「設定 AE → Maya」を押します。
  3. 受け取る側に、変わる内容（例「FPS: 24 → 30」）の確認ダイアログが出ます。「適用」を押すと変わります。

  ・時間の対応は転送と同じです。Maya の Origin frame が、AE のコンプの 0 秒になります。
    AE のコンプの開始フレームも Origin frame にするので、AE と Maya で同じフレーム番号が表示されます。
    ・アニメーション範囲 ⇔ コンプ（Origin frame から始まる長さ）
    ・再生範囲 ⇔ ワークエリア
  ・Maya の FPS を変えても、キーはフレーム番号のまま動きません。
  ・Maya が対応していない FPS（18 など）は送れません。
  ・同じ設定のときは何も変えません。元に戻すときは、受け取った側で取り消し（Ctrl+Z）を 1 回押します。


■ タイムスライダーの同期

  「タイムスライダーを同期」にチェックを入れると、Maya と After Effects のどちらで時間を動かしても、
  もう片方が同じ時間に移ります（Maya の Origin frame = AE のコンプの 0 秒）。

  ・スイッチは Maya と AE のパネルで共通です。どちらで切り替えても両方に反映されます。
  ・チェックを入れた側の時間に、もう片方が合わせます。
  ・「再生中も追従」: オフ（既定）なら、Maya の再生中は AE を動かさず、止めた位置に合わせます。
    オンにすると再生中も追従しますが、AE の表示が追いつかないことがあります。
  ・AE からは、0.05 秒ごとに AE の時間を確認して Maya に送ります（少し遅れて追従します）。
  ・Maya から動かしたときの遅れは、主に AE がフレームを描き直す時間です。AE のビューアの解像度を
    「1/2」や「1/4」にすると速くなります。
  ・AE はアクティブなコンプ（最後にクリックしたタイムライン）の時間を使います。


■ SyncBridge Monitor（スタートメニュー →「SyncBridge Monitor」）

  SyncBridge のサーバー（Maya と AE の間で転送を仲介する、画面のないプログラム）の様子を確認します。
  ・動作中のサーバーの一覧、接続中のアプリ（Maya / After Effects）、転送の履歴、ログ
  ・「停止」: サーバーを止めます（Maya や AE から再び Connect すると、新しく起動します）
  ・「強制終了…」: 応答しなくなったサーバーを止めます
  ・「切断…」: 選んだアプリをサーバーから切断します
  モニターを閉じても、サーバーや転送には影響しません。


■ 困ったとき

  ・「素材は ○ 秒ですが、○〜○ 秒が必要です」/「値 ○ は 0 から ○ の範囲外です」:
      タイムワープの「値」（元のアニメーションの何フレーム目を見せるか）が、AE の素材の長さを超えています。
      AE の素材は、Maya でタイムワープを無効にしてレンダーした連番なので、ワープで使うフレームを
      すべてレンダーしておく必要があります。
      - Maya の Origin frame を、素材の 0 フレーム目にあたる Maya のフレームに合わせる
      - 素材が短い場合は、レンダー範囲を広げる（テスト用のコンポなら長さを延ばす）
      - Maya の Scene Time Warp の値の範囲は、作成した時点の再生範囲で決まります。
        再生範囲を変えた場合は、Scene Time Warp を作り直してください。
  ・「SyncBridge サーバーが起動していません」: 先に Maya のパネルで Connect を押してください。
  ・「ポート 8765 はほかのプログラム（…）が使っているため、ポート 8766 で…起動しました」:
      そのまま使えます。SyncBridge が空いているポートを自動で選びました（AE のパネルも自動でそちらにつながります）。
  ・「ポート 8765〜8774 がすべて使われています」: メッセージに出ているプログラムを終了してから、もう一度 Connect を押してください。
  ・「レイヤーを 1 つだけ選択してください」: AE で、送り先のコンポを開いてレイヤーを 1 つ選んでください。
  ・After Effects のメニューにパネルが出ない / 真っ白: After Effects を再起動してください。
    それでも出ない場合は、下のログと一緒に担当者へ連絡してください。
  ・ログ: SyncBridge Monitor の「ログ」タブ、または %LOCALAPPDATA%\SyncBridge\logs（Monitor の「ログフォルダを開く」）


■ アンインストール

  「%LOCALAPPDATA%\Programs\SyncBridge」の「Uninstall.bat」をダブルクリックします。
  （エクスプローラーのアドレス欄に上の文字をそのまま入れると開けます）
  先に Maya を終了してください（Maya は終了時にシェルフを保存し直すため）。
  Maya のシェルフの「SyncBridge」タブも消えます。ドラッグ＆ドロップで追加したボタンは、
  ボタンを右クリック →「削除」で消してください。
  スタートメニューの「SyncBridge Monitor」も一緒に消えます。


■ 更新

  新しい zip を解凍して、同じように Install.bat を実行してください（上書きされます）。
  Maya のシェルフの「SyncBridge」タブとボタンは、そのまま使えます。
  （0.1.4 以前にドラッグ＆ドロップで追加したボタンも使えます。不要なら右クリック →「削除」）
